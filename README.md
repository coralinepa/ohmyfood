OhMyFood – App mobile de réservation de menus

OhMyFood est une application mobile-first permettant aux utilisateurs de précommander des menus gastronomiques dans des restaurants partenaires.
Ce projet met l'accent sur la mise en page responsive, l’animation CSS avancée et l’intégration d’une interface utilisateur fluide à partir de maquettes Figma.

Compétences mises en œuvre
- Intégrer une maquette Figma en HTML/CSS
- Développer une interface responsive mobile-first
- Utiliser SASS pour organiser les styles
- Implémenter des animations CSS (transitions, chargement, icônes)
- Gérer la structure d’un site statique

Fonctionnalités principales
- Page d’accueil listant les restaurants
- Pages restaurant avec menu détaillé
- Animation de chargement des plats
- Boutons de “like” (❤️) animés
- Navigation fluide entre pages
- Design 100% responsive

Technologies utilisées
- HTML
- SCSS 
- CSS Animations & Transitions
- Mobile-first responsive design
- Git & GitHub
